Подключение клиента

Один раз на машине или в образе направить канал pecl.php.net на этот сервер:

{% if mirror %} 
pecl channel-update {{ public_base }}/channel.xml
pecl config-set preferred_mirror {{ mirror }}

preferred_mirror нужен для работы без интернета: перед каждой установкой pecl проверяет channel.xml своего канала и без этой настройки обращается к pecl.php.net, а при его недоступности падает.

{% else %} 
pecl channel-update {{ public_base }}/channel.xml

Сервис опубликован не на порту 80/443, поэтому его нельзя указать как preferred_mirror: без доступа к pecl.php.net команда pecl install упадёт на проверке channel.xml. Опубликуйте сервис на 80/443 (например, за nginx).

{% endif %}

Дальше установка как обычно, все запросы идут через прокси:

pecl install redis

В Dockerfile:

RUN pecl channel-update {{ public_base }}/channel.xml \
{% if mirror %} && pecl config-set preferred_mirror {{ mirror }} \
{% endif %} && pecl install redis-6.3.0

Команда pecl update-channels при доступном интернете вернёт канал на оригинальный pecl.php.net; после неё повторите команды подключения.
